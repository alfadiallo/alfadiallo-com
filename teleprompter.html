How to set up the sheet
  1. In row 1, type Title in A1 and Script in B1.
  2. Add one script per row: its name in column A, the full text in column B. Line breaks inside the cell are kept.
  3. Tap Share, then set General access to Anyone with the link, Viewer.
  4. Copy the link and paste it above. To use a particular tab, copy the link while that tab is open.

Anyone who has the link can read the sheet, so keep confidential material out of it. The link is saved on this device only. Words in [square brackets] show as cues to read silently.

Two devices

Link a phone and an iPad so both show the same script at the same place, and either one can start, pause and change speed.

On the other device, open this page, go to Settings, and type this code under "Join with a code".

How linking works

Both devices need to be online. They find each other through a free pairing service, then talk to each other directly. Each device keeps its own text size, mirror and color settings; the script, position, speed and timer are shared. The code stays the same until you turn sharing off.
